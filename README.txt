ASMA MOHAMED — PERSONAL PORTFOLIO

Files
- index.html: portfolio content and structure
- style.css: responsive design, color system, layouts, and animations
- script.js: mobile navigation, reveal-on-scroll, active section links, and subtle cursor glow
- assets/images/: place your personal portrait here as asma-photo.jpg

Run locally
1. Extract the folder.
2. Open index.html in a modern browser, or use the Live Server extension in VS Code.
3. Add assets/images/asma-photo.jpg to replace the portrait placeholder.
4. Review each GitHub repository link and certificate detail before publishing.
5. To enable Download CV, add your PDF (for example assets/Asma-Mohamed-CV.pdf), then update the disabled Download CV link in index.html to point to that file and remove aria-disabled="true" and the is-disabled class.

Notes
- Built with plain HTML, CSS, and vanilla JavaScript; no framework required.
- Google Fonts are loaded online. If offline, fallback fonts are used.
- Project artwork is made with CSS and is illustrative, not a screenshot of each project.
- This starter does not yet include a working Download CV button because the PDF has not been added.
